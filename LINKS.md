# Link and Reference Discipline

Use descriptive relative links and reciprocal English/German project/guide
navigation. Check affected local links for bounded changes; broader external
link checking belongs to applicable milestones.

Conversation claims trace to actual external transcript evidence. Locators,
timestamps, private paths, participant data and review decisions stay external.
Never invent missing evidence or turn speaker attribution into certainty.
Tracked project docs use generic logical roots only, without concrete conversation
links or sync endpoints. References grant no file access or sharing approval.
