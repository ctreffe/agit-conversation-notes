## Next design step

Jointly define schema and drafting method: detailed thematic content preparation
for personal recall, source verification, uncertainty and distinct results,
decisions, tasks and open questions. Do not organize by speaker or invent data.

## Planned conversation cycle

1. Select exact external files and scoped access/write authority.
2. Preserve original Whisper JSON; create derivatives externally.
3. Produce a German thematic QMD using the later agreed skill.
4. Verify content/evidence and render bounded external DOCX for maintainer review.
5. Return accepted corrections to QMD with external baseline/decision trace.
6. Re-render and check changed content, storage boundary and unresolved questions.

lineage and selected adoption. Review, consistency, retrospective and visual
