# Screenshots and Visual Files

No screenshots are needed for initialization or the first content-focused trial.
Conversation visuals, document page images and intermediates stay external and
unversioned under [CONVERSATION_STORAGE.md](CONVERSATION_STORAGE.md).
Generic workflow visuals may enter repository documentation only when they
contain no conversation data and are authorized for that use.

Use visuals to clarify real tasks. Check private data, metadata and disclosure
boundaries. Agent inspection of current rendered surfaces requires explicitly
selected visual-inspection. Rendering and technical checks are separate.
